# Vue 3 + TypeScript + Vite

## 遊戲回合規則

勝出條件：第一位「每月被動收入 ≥ 每月總支出」的玩家自動獲勝。被動收入只包含目前持股的模擬月股利及房產／事業月現金流，不含薪水、賣股款或一次性事件收入。買進資產、還款或事件結算後立即檢查所有玩家；同一個全體事件讓多人同時達標時並列獲勝。宣布結果後停止擲骰、交易、借還款及回合推進，保留資產供查看；連線同步勝者及達標時的收入／支出。可返回選單開始新局，不需手動按「進入快車道」。

連線建立或加入房間需填寫非空白暱稱，不會自動替換成「無名氏」。同一瀏覽器在等待室再次加入時，會更新自己的暱稱及職業；遊戲開始後重新連線則保留本局原有身分與資產。不同玩家需使用不同瀏覽器身分或裝置。

玩家依加入順序輪流操作。每位玩家每回合只能擲骰一次；抽到投資卡時，必須先買進或放棄（現金不足時可借款或放棄），再按「結束回合，交給下一位」。最後一位完成後回到第一位。擲骰動畫期間不能結束回合；連線模式只有目前玩家能操作。經過發薪日時，月現金流自動入帳，沒有手動領取功能。

擲骰與結束回合按鈕上下相鄰排列，交棒按鈕以明顯底色顯示；未擲骰、事件未處理或市場未關閉時仍不可交棒。事件卡現金不足時，卡片直接顯示所需金額、目前現金、差額及賣股／額度內借款／放棄的選項，並停用買進；取得足夠現金後立即恢復。連線非目前玩家也會顯示不能操作的原因。

事件卡依棋盤落點抽取：「意外之財／額外收入／好運降臨」只抽一次性收入卡，「生活開銷／帳單日／日常花費／突發支出」只抽支出卡，「家庭生活」觸發添丁事件，市場格抽全體市場卡，「機會事件」抽個人機會卡。投資格（含「新機會」）開啟股票市場，房產與置產格只抽房產卡。停在發薪日僅結算月現金流，不再抽卡；經過發薪日後仍會處理目的地事件。全體事件會套用至所有玩家。

## 市場消息卡

銀行貸款未償本金總額不得超過目前職業月薪的 6 倍；股票股利、房產／事業現金流、現金與資產價值都不會提高額度。資產面板顯示上限及剩餘額度，每次借款 $50,000，剩餘額度不足時停用按鈕；借款核心亦拒絕超額、非正數或超過兩位小數的金額，適用單機與連線。部分或全額還款後恢復相應額度。舊局若已超額，不強制扣款或刪除負債，但不能再借，直到還款後有足夠額度。此限制防止無限借款堆疊固定模擬股利，股利與勝出條件維持不變。

銀行貸款可在資產與負債面板輸入金額「部分還款」，或按「還清」。部分還款扣除現金與本金，月付款改為剩餘本金的 2%（四捨五入至整元），還清後移除負債。金額須為正數、最多兩位小數，且不超過餘額或現金；連線僅目前玩家可還款。房貸、車貸、信用卡月付規則不變。

市場消息共 15 張，由「市場消息／市場事件／新點子」格隨機等機率抽取並立即套用至全體玩家，結果顯示於旅程紀錄；無相關資產或負債者不受該類事件影響。這些是桌遊模擬消息，不對應歷史當日新聞，也不修改證交所股價。

新增 10 張：

| 消息 | 效果 |

## 股票市場與行情服務

機會卡另有「雙骰加速機會」與「三骰衝刺機會」：抽到後立即播放追加 2／3 顆骰子的動畫與音效，合計點數移動，經過發薪日自動領取並正常觸發新落點事件。追加擲骰不交棒、不前進行情日期，也不恢復一般擲骰次數；完成前不能進股市或結束回合。連線同步待擲顆數及結果，由目前玩家執行。

「機會事件」使用獨立九張卡，只影響踩到的玩家，不再抽市場消息。專案接案收入 $18,000、合作推薦獎勵 $12,000、創意提案獎金 $25,000、講師邀約收入 $8,000 為一次性自動入帳；合夥行動咖啡攤投入 $60,000、每月現金流 $1,500，二手自動販賣機經營權投入 $40,000、每月現金流 $1,000，需選擇買進或放棄。創業卡不會出現在一般房產卡池，現金不足可先借款或賣股，未處理前不能結束回合。

新增「失業」：立即記錄，抽到當回合不計入停玩次數；接下來三次輪到該玩家時，只能按「跳過回合，交給下一位」，不能擲骰、股票交易或借還款，每次交棒扣一次停玩次數，第四次恢復正常。跳過期間棋子不移動、不額外發薪或抽卡，職業薪資、既有資產與收支設定不變，全體事件仍可影響該玩家。跳過回合仍計入輪次，最後一位交棒照常推進歷史行情；連線同步剩餘停玩次數。舊局缺少停玩欄位視為正常玩家。

市場表格顯示每檔目前持股的「平均成本 / 股」，選取股票後顯示「平均購入成本 / 股」與「持股總成本」。平均成本為剩餘各批持股成本合計除以股數，非本輪收盤價；沒有持股時顯示「—」。部分賣出依先買先賣扣除持股，成本隨剩餘批次重新計算；分割、減資沿用調整後成本。成本不包含模擬股利、消息卡現金收支或交易費用。資產面板另列各批每股與總成本。

自己的回合可使用遊戲現金，依證交所 2020–2026 年歷史每日收盤價買賣台積電、0056、0050、鴻海、聯發科、中華電信、國泰金及長榮。從 2020 年第一個交易日（2020-01-02）開始，所有玩家完成一輪才前進一個交易日，自動跳過休市日；沒有踩到投資格的輪次也會前進。同輪及連線房間共用固定行情快照，開啟市場不會刷新換價。每輪取得行情後才能擲骰；失敗可重試，不會使用舊價或固定價格備援。2026 年僅使用已公布資料，沒有下一日資料時停止推進，不循環或使用未來價格。

採自由玩法：輪到自己的回合、本輪行情就緒時，可按「進入股票市場」，不必踩到投資格，擲骰前後均可買賣。離開後可在同一回合再次進入，不刷新行情；投資格仍自動開啟市場。其他玩家的回合不可操作。買進為正整數（1 股起），賣出可包含減資後的小數持股（最多六位小數），不限交易次數。必須離開市場才能擲骰或結束回合；每回合仍需擲骰一次，待處理事件卡也不會因進出股市而消失。停牌或缺少當日報價的股票不可交易，不沿用上一日價格。

此為模擬交易，沒有真實下單、不計交易費用或稅。股利沿用桌遊設定，不代表真實配息；市場事件維持原遊戲現金損益結算；資產總額的股票部分按購入成本計算。已處理 0050 在 2025-06-18 一拆四：全體持股 ×4、成本及每股模擬股利 ÷4，總成本與被動收入不變。分割後買進也使用調整後股利。已處理長榮在 2022-09-19 減資 60%：持股 ×0.4、每舊股退還 $6、調整成本並保留小數持股；退還款簡化為復牌日入帳，非真實付款時程。這不是完整含息回測，其他現金股利、公司行動未全面模擬。

資料來源：[台灣證券交易所個股月成交資訊](https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=20200101&stockNo=2330)。透過同源 `/api/quotes?date=YYYY-MM-DD` 代理，按需下載月份（非預先儲存完整七年資料）。每批並行兩檔，歷史月份記憶體快取 24 小時，當月快取 10 分鐘，單次下載逾時 15 秒、前端整輪等待上限 70 秒。不需要 API 金鑰，也不會傳送玩家資料至證交所。

- 開發：`npm run dev`，預設 `http://127.0.0.1:5173`（明確綁定 IPv4，避免 localhost 僅監聽 IPv6 時無法連線）。亦可執行 VS Code 工作「開發遊戲（IPv4 本機）」；需保持開發伺服器執行，行情 API 與頁面共用同一服務。網路連線失敗時會提示檢查伺服器並重試，不使用固定股價備援。
- 正式：`npm run build`，然後 `npm start`（需支援內建 fetch 的 Node.js 22.12+）。
- 正式服務預設 `http://127.0.0.1:3000`；部署時使用 `HOST=0.0.0.0` 與平台提供的 `PORT`。Windows PowerShell 可設定 `$env:HOST='0.0.0.0'; $env:PORT='3000'; npm start`。
- 不可僅靜態部署 `dist`：必須保留 Node.js 行情服務，或將 `/api/quotes` 路由至該服務。

## Firebase App Hosting 部署

此專案已加入根目錄設定檔 [apphosting.yaml](C:/Users/Owner/tcashflow/apphosting.yaml)，會在 Firebase App Hosting 上：

- 以 `npm run build` 建置前端
- 以 `npm start` 啟動 [server.mjs](C:/Users/Owner/tcashflow/server.mjs)
- 在執行期自動設定 `HOST=0.0.0.0`
- 一併部署 [dist/](C:/Users/Owner/tcashflow/dist)、[server/](C:/Users/Owner/tcashflow/server) 與 Node 入口檔，保留 `/api/quotes`

部署步驟：

1. 將專案推到 GitHub。
2. 到 Firebase 主控台開啟 **App Hosting**。
3. 選擇 **Connect repository**，連到這個 GitHub repo。
4. 分支選擇要部署的 branch（通常 `main`）。
5. Root directory 選 repository 根目錄，也就是含有 [package.json](C:/Users/Owner/tcashflow/package.json) 與 [apphosting.yaml](C:/Users/Owner/tcashflow/apphosting.yaml) 的位置。
6. 建立 backend 後等待首次 build 完成。

補充：

- App Hosting 會提供 `PORT`，不需要自行設定。
- 這個專案不能用 Firebase 靜態 Hosting 直接部署，因為 [server.mjs](C:/Users/Owner/tcashflow/server.mjs) 的 `/api/quotes` 需要 Node.js 執行。
- 若之後要加 Firebase Secret 或其他環境變數，可直接擴充 [apphosting.yaml](C:/Users/Owner/tcashflow/apphosting.yaml) 的 `env` 區段，或在 Firebase Console 的 App Hosting 設定頁新增。
